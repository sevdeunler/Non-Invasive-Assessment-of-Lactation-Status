# Non-Invasive-Assessment-of-Lactation-Status
Thermal Image Processing for Breast Milk Detection in Postpartum Mothers Using Computer Vision and Machine Learning

# Thermal Breast Image Analysis

This project focuses on the analysis of thermal breast images obtained from postpartum mothers. Image processing techniques such as segmentation, contour detection, masking, and thermal feature extraction are used to prepare the data for artificial intelligence applications.

The main objective is to investigate whether thermal patterns can be used to estimate milk presence and distribution while distinguishing them from other heat sources visible in thermal images. Current work includes preprocessing and dataset preparation for future machine learning and deep learning models.
